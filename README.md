# project_LIDA_AP
structure: 
 - data:
   - raw: The data that stores the original data. There are a few assumptions, the rheological data are not uniform, and most rheological flow laws have ad hoc equation. I tried to create a common framework.
   - processed: the data are are processed, and converted into the unit of measure that will be used in the code
   - result: plot concerning the rheological flow law, and thermal properties 
   to be used in the main manuscript.  


Small project to convert rheological, thermal properties data in data structure that are required to a thermo-mechanical code. 
Must have: 
- raw database where the data from litearature are collected and referenced accordingly 
- the final data base/data structure 
- picture representing the P-T dependency/strain rate
